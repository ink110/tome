# tome-spread · 传播复盘

从一堆内容里，找出真正被传播的那几条，拆开看它们为什么有效，再变成自己能用的选题。

**目标不是「分析所有内容」，是「只提炼传播广、有数据或可核验代理指标、影响力大的那几条」。可以少，不要多。**

## 输入

| 输入 | 从哪来 | 必需 |
| --- | --- | --- |
| 每条内容的传播数据 | `_manifest.json` 的 `stat`；微信没有，用代理指标 | 是 |
| 高传播内容的原文 | `00-收集/` 的蒸馏稿 + 原文 | 是 |
| 文章 URL / 发布时间 | `_manifest.json` 的 `source_url` / `published` | 是 |
| 人物画像的「表达 DNA」「人物标签」 | `10-画像/` | 建议 |
| 外部传播证据（媒体引用、转载、跨平台） | WebSearch | 可选 |

没有 manifest 时，先用对应采集 skill 生成清单；不要凭截图或记忆判断。**微信不公开阅读 / 在看 / 转发数，`appmsgstat` 为空，不要估算**；改用代理指标，见 `references/selection.md`。

## 流程

| 步 | 做什么 | 读 |
|---|---|---|
| 1 | 有互动数据用 `scripts/rank.py`；没有就建代理指标表 | `references/selection.md` |
| 2 | 定性筛选：只留 8–12 条真正符合「传播广」的 | `references/selection.md` |
| 3 | 逐条拆：钩子、结构、故事模板、证据、可复用点 | `references/case-card.md` |
| 4 | 从案例反推 10–15 个选题 + 3–5 个结构模板 | `references/topics.md` |
| 5 | 写进 `20-输出/`，并作为书的第三篇 + 附录 F/G | 本文「输出」 |

## 输出

```text
20-输出/
├── <人物>·传播案例库.md      # 8–12 个案例，每个一个 H1
├── <人物>·选题清单.md        # 10–15 个选题
└── <人物>·内容结构模板.md    # 3–5 个可复用结构
```

书里的位置：

- `传播案例库.md` → `第三篇 · 传播案例`，每个 H1 一篇。
- `选题清单.md` → `附录 F · 选题清单`，一篇一章。
- `内容结构模板.md` → `附录 G · 内容结构模板`，一篇一章。
- 重跑 `tome-portrait` 的成书命令即可；微信项目用 `--config`，见 `tome-book/references/wechat-book.md`。

## 筛选标准

先过硬门槛：**有可核验的数据或代理指标，且至少满足 4 条中的 3 条**。

**平台有互动数据**（B 站等）：

1. 站内数据在合集里排前 20%。
2. 互动率（点赞+投币+收藏+评论+转发 / 播放）明显高于合集中位数。
3. 有站外传播证据：媒体报道、二创、跨平台引用、被同行讨论。
4. 发布超过 6 个月仍有稳定数据，或反复被引用。

**平台不公开互动数**（微信公众号等）：

1. 站内回引：后续文章直接链接 + 完整标题提及。
2. 站外转载：独立站点整篇转载，逐站核验。
3. 引用跨度：发布后 6 个月以上仍被引用。
4. 独家材料：一手数据、问卷、工具记录等别人拿不到的内容。

四项至少满足三项。不满足的，不进入案例库。**不要为了凑数放「播放高但互动低」「标题党」，更不要估算微信阅读量。**

## 案例卡

每条一个 H1，固定小节：

```markdown
# S01 · <标题>

## 传播数据
## 为什么传播
## 钩子
## 结构拆解
## 故事模板
## 证据
## 可复用点
## 我的改编
## 边界
```

字段细节见 `references/case-card.md`。每条必须带数据快照日期，或写清代理指标的口径与统计范围。微信案例不要套用播放 / 投币字段。

## 选题清单

每条字段：选题、角度、为什么现在、用哪条证据、目标平台、钩子方向、形式、难度、我的优势、风险。细节见 `references/topics.md`。

## 四条规矩

1. **数据是快照**：记录抓取日期；不同平台的数据不可直接比较；拿不到就不写。
2. **不编数据、不编链接**：文章链接只取 `_manifest.json` 的 `source_url`；不要用「下一篇」链接、不要自己拼 `chksm`。
3. **相关不等于因果**：播放高可能是推荐算法、热点、标题，不一定是内容结构好；要找到可复用的结构，不要神化单条数据。
4. **只拆传播，不抄内容**：引语逐字；概括必须标「转述」；站外转载数逐站核验，不能把相邻文章算进来。

## 什么时候读哪个文件

| 场景 | 读 |
|---|---|
| 指标口径、排名、阈值、候选清单、无互动数据时的代理指标 | `references/selection.md` |
| 案例卡字段、示例、拆解方法 | `references/case-card.md` |
| 选题字段、平台差异、优先级、内容结构模板 | `references/topics.md` |
