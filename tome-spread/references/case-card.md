# 案例卡

> 一张卡只回答一件事：这条内容为什么被传播，我能不能用同样的结构做出自己的内容。
> 不是内容摘要，不是观后感。

## 二、钩子怎么拆

看前 15 秒（或前 3 句），回答：

1. 他第一句给了什么**信息差**？
2. 他让观众产生了什么**情绪**？
3. 他承诺了什么**收益**？
4. 他制造了什么**未完成感**（想知道后面）？

常见钩子类型：

| 类型 | 句式 | 风险 |
| --- | --- | --- |
| 反常识 | 「你以为……其实……」 | 容易变成标题党 |
| 利益承诺 | 「看完这条，你会……」 | 承诺必须兑现 |
| 冲突 | 「所有人都说……我偏不」 | 容易树敌 |
| 身份认同 | 「如果你是……」 | 圈子太小会限流 |
| 悬念 | 「我先说结论……」 | 结论必须够硬 |
| 恐惧 | 「再不……就晚了」 | 容易制造焦虑 |

## 三、结构怎么拆

不要按「第一段、第二段」拆，按**功能**拆：

- 钩子：让人停下来。
- 铺垫：让人相信这个问题和他有关。
- 冲突：让人产生「但是……」
- 转折：给出新的解释 / 方法。
- 收束：给一个可记住的句子 / 行动。

如果一条内容没有冲突和转折，只有「观点 + 例子 + 总结」，它可能靠人物光环或选题，不是靠结构。标出来。

## 四、故事模板怎么提炼

一个好模板要满足：

- 能用一句话说清骨架。
- 换一个主题仍然成立。
- 有明确的「不适合场景」。

例：

```text
模板：反常识结论 → 我当年的错误 → 三年后的结果 → 你现在可以怎么做
适合：个人经验、投资、职业选择
不适合：纯新闻、纯知识科普、需要大量数据的主题
```

## 五、质量检查

- [ ] 数据完整，带快照日期；微信写代理指标，不估算阅读量。
- [ ] 有原链接，且来自 `_manifest.json` 的 `source_url`。
- [ ] 钩子写了逐字原话，不是概括；转述已标「转述」。
- [ ] 站外转载数逐站核验过，没有把相邻文章或同一站点多个栏目重复计数。
- [ ] 结构按功能拆，不是按段落复述。
- [ ] 故事模板一句话能说清，且写了不适合场景。
- [ ] 可复用点具体到「我下一句怎么写」，不是「要有个好钩子」。
- [ ] 边界写了时效、平台、人物光环、伦理风险。
- [ ] 没有复制原内容的大段文字。
