# 选题清单

> 选题不是「我想讲什么」，是「谁在什么场景下会停下来听」。
> 从传播案例反推选题，不要凭空想。

## 一、模板

```markdown
# <人物>·选题清单

> 生成日期：YYYY-MM-DD
> 来源：传播案例库 S01–Sxx + 画像 T01–Txx

### 01 · <选题标题>

- 角度：<一句话，说明你和别人讲得不一样在哪>
- 为什么现在：<时效 / 热点 / 人群痛点>
- 用哪条证据：<S0x / T0x / Q00xx / C00xx>
- 目标平台：<视频号 / 小红书 / B站 / 公众号 / 抖音>
- 钩子方向：<反常识 / 利益 / 冲突 / 身份 / 悬念>
- 形式：<口播 / 图文 / 案例复盘 / 对比>
- 难度：低 / 中 / 高
- 我的优势：<我有什么别人没有的素材 / 视角>
- 风险：<事实 / 伦理 / 时效 / 平台>
```

## 二、怎么从案例反推

每条案例至少产出一个选题方向，最多两个。问四个问题：

1. 这个结构换一个主题，还成立吗？
2. 这个钩子换一个人群，还成立吗？
3. 我手里有没有同等强度的案例 / 数据？
4. 我能不能讲出他讲不了的那一面？

如果四个问题都是「能」，这个选题值得做；如果只有「结构能」，但证据不够，降级为「待补素材」。

## 三、选题的四个来源

| 来源 | 怎么用 | 例子 |
| --- | --- | --- |
| 传播案例 | 拆结构，换主题 | 他的「反常识 + 个人故事」，换成我的行业故事 |
| 画像条目 | 把思维模型变成可操作建议 | T07 的决策启发式 → 「我如何判断一个机会」 |
| 金句 / 案例 | 一句话一个选题 | 一句反常识的话 → 一条 60 秒口播 |
| 外部争议 | 用事实做对比，不站队 | 「他说 vs 他做」的差距 → 一条复盘 |

## 四、平台差异

| 平台 | 更适合 | 钩子 | 长度 |
| --- | --- | --- | --- |
| 视频号 | 熟人转发、观点、故事 | 身份认同 / 利益 | 1–3 分钟 |
| 小红书 | 清单、经验、对比 | 利益 / 反常识 | 图文 6–9 图 |
| B站 | 深度、案例、复盘 | 悬念 / 反常识 | 5–15 分钟 |
| 抖音 | 冲突、情绪、快节奏 | 冲突 / 恐惧 | 30–60 秒 |
| 公众号 | 长文、系统方法 | 利益 / 身份 | 2000–5000 字 |

同一选题不要原样搬五个平台；换钩子和结构，不换核心证据。

## 五、优先级

按「证据强度 × 我的优势 × 时效」排：

- P0：我有独家素材 / 视角，且现在有热度。
- P1：证据强，但时效一般；可以做常青内容。
- P2：结构好，但证据不足；先补素材。
- 放弃：只有情绪，没有证据；或事实风险太高。

一次最多 15 条；宁可 8 条能做的，不要 15 条空泛的。

## 六、内容结构模板（附录 G）

从案例里提炼 3–5 个可迁移骨架，写到 `<人物>·内容结构模板.md`。每个模板固定字段：

```markdown
## 模板一 · <名字>

- 来源：S0x
- 适用：<平台 / 主题 / 长度>
- 骨架：<四到六步，按功能写>
- 句子模板：<2–3 句，可替换关键词>
- 失败条件：<什么情况下这个结构会失效>
```

- 模板是骨架，不是原句；不要把案例原文大段搬进来。
- 每个模板必须写「失败条件」，否则会变成万能公式。
- 末尾可加一张「目标 × 组合 × 长度」建议表，但不要超过一屏。

## 七、质量检查

- [ ] 每条有明确角度，不是「聊聊某某」。
- [ ] 每条能指到具体的案例 / 画像条目 / 引语。
- [ ] 每条写了目标平台和钩子方向。
- [ ] 每条写了风险和不能用的部分。
- [ ] 没有把「人物原话」直接当自己的观点。
- [ ] 没有事实不确定却写成确定的内容。
- [ ] 模板有来源、骨架、失败条件，且能换主题成立。
