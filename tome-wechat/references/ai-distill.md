# 本地模型提炼（阅读卡片 / 标签 / 去重）

> `wechat_distill.py` 的细节。目标：打开笔记先看到提炼，再看到原文。
> 模型档位由配置决定：`claude`（默认，Claude Code 直接做）、`openai`、`ollama`。

## 命令

```bash
# 全量（可断点续跑；已有 ai_distilled: true 的自动跳过）
python3 ~/.claude/skills/tome-wechat/wechat_distill.py --topic <专题名>

# 冒烟：只做 1 篇，不去重
... --topic <专题名> --limit 1 --no-dedup

# 全部重做（会先备份到 .backups/<时间戳>/）
... --topic <专题名> --force

# 只重新生成去重报告
... --topic <专题名> --dedup-only
```

- `wechat-ai` 区块是唯一由模型生成的区块；`--force` 只替换它。
- 原文区和出处块由程序原样搬移；有备份可回滚。
- 标题 H1 在 AI 区块内；如果删除 AI 区块，笔记回到抓取时的形态。

## 模型与参数

- 模型：由 `models.provider` 决定；本地 `qwen2.5:14b` 约 9GB，32b 约 20GB。
- `format: json`，`temperature: 0.2`，`num_ctx: 32768`，`num_predict: 1800`。
- 串行调用，模型常驻 30 分钟；单篇约 30–60 秒（实测 37.6s）。
- 输入会去掉图片 / Eagle 链接 / HTML 注释；正文超过 24,000 字时取前 20,000 + 后 4,000。
- 金句会校验是否为原文连续片段（忽略空白），模型改写过的会被丢弃。

## 标签

- 模型输出 5–10 个中文名词短语，存进 `ai_tags`，不覆盖原有 `tags: [clippings]`。
- 正文「## 标签」用 `·` 分隔、不带 `#`，避免污染 Obsidian 标签面板。
- 需要按标签检索时用 Dataview / 搜索 `ai_tags`。

## 去重

1. **候选生成（本地、确定性）**：
   - 标题相似度 ≥ 0.72；或
   - 正文 3-gram Jaccard ≥ 0.35；或
   - `ai_topic_key` 相同且 Jaccard ≥ 0.18。
   - 按相似度排序，最多取 40 对。
2. **模型确认**：把两篇的标题、摘要、正文节选（各 3,500 字）给模型，输出
   `{"relation": "duplicate|series|related|different", "confidence": 0-1, "reason": "..."}`。
   - `duplicate`：核心内容（方法、数据、结论、案例）高度重合，读一篇即可；
   - `series`：同一系列/栏目的不同期、不同月份、不同版本（如月度热搜词、教程第 1 篇 vs 第 3 篇）；
   - `related`：主题相同但内容、案例、数据或结论不同；
   - `different`：主题或内容不同。
   只有 `duplicate` 且 `confidence>=0.7` 才计入「确认重复」，避免把同系列文章误判为重复。
3. **输出**：`_meta/reports/_dedup.md`，分「重复簇（建议每组只保留 1 篇）/ 确认重复（逐对证据）/
   同主题系列（不视为重复）/ 主题相关但内容不同」四节。重复簇用并查集把逐对关系合并，
   每组建议保留正文最长的一篇；**只标记，不删除**。其余候选供人工判断。

## 报告

- `_meta/reports/_ai-report.md`：提炼成功/跳过/失败、内容类型分布、高频标签 Top 20、去重入口。
- `index.md` 增加 `<!-- wechat-ai-report -->` 区块，链到上面两个报告；重复运行只替换区块。

## 幂等与恢复

- 判断依据：frontmatter `ai_distilled: true`。中断后重跑只处理剩余篇目。
- 每次改笔记前，复制到 `~/.claude/skills/tome-wechat/.backups/<时间戳>/`。
- 单篇失败（模型输出非法 JSON / 超时）会重试一次；仍失败则记录并继续，退出码 3。
- 退出码：0 全成功 / 1 没有笔记 / 2 Ollama 或模型不可用 / 3 部分失败 / 4 全失败 / 130 Ctrl-C。

## 已知边界

- qwen2.5 可能给出泛化标签（如「小红书」）或泛化论证结构；提示词已约束，但仍需人工抽查。
- 「案例速查表」在无独立案例时会明确写“本文无独立案例”，不硬编。
- 去重是语义级辅助判断，不替代人工终审；不会自动删除或合并文件。
