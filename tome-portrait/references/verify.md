# 核验

> 核验不是「找黑料」，是回答一个问题：这条结论，我凭什么信？
> 目标不是把人物写坏，也不是把他写神；是让每条结论都有可追溯的证据和明确的边界。

## 一、三星标准

每条画像条目（T01–T36）都要打星。三个条件：

| 条件 | 什么算满足 |
| --- | --- |
| A 言行一致 | 他说的，和他后来做的，能对上；不是只在一场口播里说过 |
| B 可核验数据 / 文件 | 有数字、财报、链上记录、司法文件、官方公告、原始视频等可查的东西 |
| C 具体案例 / 独立来源 | 有完整的场景和因果链，或有至少一个独立于他本人的来源 |

| 星级 | 判定 |
| --- | --- |
| ★★★ | A + B + C 全满足，且没有明显反证 |
| ★★ | 满足其中两项；或三项都有但有一项较弱 |
| ★ | 只有他本人的自述 / 单一二手来源；没有数据、没有案例、没有独立证据 |

补充规则：

- 有矛盾证据时，降一星，并把矛盾写进核验表。
- 口头重复不算独立证据；同一套话在 10 集里出现，只算 1 个来源。
- 外部来源之间互相转引，不算多个独立来源；要找到最初的出处。
- 没有外部材料的条目，最高只能 ★★；除非有可核验的原始记录（如链上数据、财报）。
- 不要为了凑比例故意找负面材料；也不要用「没有负面」当 ★★★ 的理由。

## 三、矛盾清单怎么写

每条矛盾回答五个问题：

1. 哪个条目？
2. 说法 A 是什么？谁说的？在哪？
3. 说法 B 是什么？谁说的？在哪？
4. 哪一方证据更强？为什么（原始文件 > 媒体报道 > 自述）？
5. 当前判断是什么？是「以 B 为准」，还是「暂时并列，待核验」？

写法示例：

```markdown
| T16 | 他说「从来没有拿过用户的钱」（口播 045，2017） | 外部文件显示某项目资金流向关联方（E012，【权威媒体】🔶指控） | 外部文件更强，但仍是指控，未有判决 | 口播记为「他说的」；正文不写定性，附录 B 列冲突 |
```

## 四、反证搜索

对每条 ★★★ 和每条核心结论，至少做一次反证搜索：

```text
<人物> <结论关键词> 反例
<人物> <结论关键词> 失败
<人物> <结论关键词> 批评
<人物> <结论关键词> 诉讼
<人物> <结论关键词> 改口
```

记录：

- 搜了什么
- 找到什么（标题 + URL + 来源层级）
- 是否改变结论（是 / 否 / 降星）
- 如果没找到，写「未找到反例」，不要写「证明成立」

## 五、铁律

1. **起诉 ≠ 定罪**。起诉书是指控，不是判决。
2. **和解 ≠ 认罪**。和解通常包含「不承认也不否认」；不能写成「认罪」。
3. **指控 ≠ 事实**。单一来源的指控只能写「有报道称 / 被指控」，不能写成「他做了」。
4. **判决 ≠ 全部真相**。判决只解决法律问题，不解决道德问题；两者分开写。
5. **自述 ≠ 事实**。他自己的话是「他说的」，不是「发生了什么」。
6. **沉默 ≠ 默认**。没有回应不等于承认。
7. **删除 ≠ 不存在**。下架、删帖、改口，都是时间线的一部分，不是没发生。

## 六、证据不足时怎么办

- 降星，不删条目。
- 在正文写「待核验」，在附录 B 写「未证实」。
- 如果是核心结论但只有 ★，考虑把它从「观点」降级为「他的自述」，或移到「表达 DNA」而不是「心智模型」。
- 如果是反面案例但证据不足，保留线索，标 `❓传闻`，不要写进正面结论。

## 七、核验完成检查

- [ ] 每条 T 条目都有星级。
- [ ] 每条 ★★★ 都有至少一次反证搜索记录。
- [ ] 矛盾清单里的每条都有「哪方更强」和「当前判断」。
- [ ] 未证实清单没有混进正文的定性。
- [ ] 和解案件写明「不承认也不否认」；没有写成「认罪」。
- [ ] 核验表的条目数与画像一致。
