# 画像体例

> 画像 2.0 = 传记体案例版。目标不是「分析得深」，是「读得下去、查得到原话、能拿去做内容」。
> 这份文件同时是写作规范和排版规范。写作和排版冲突时，以排版规范为准（手机阅读优先）。


- `movable-skills` 是跨人物连接索引；同类技能以后可以横向对比。
- `same-question-bank` 固定写 `tome-portrait/v1`（旧项目里的 `portrait/v1` 等价，不要求回改），同题题库见本文第七节。
- 版本号只增不改；2.1 在 2.0 基础上增量，不覆盖。

## 三、每条的固定四段

```markdown
### 01 · <一句话标题>

**背景**
（还原当时的场景：他站在哪儿、面对谁、为什么说这句话）

**观点**
（他的原话 / 原模型。逐字引语用「」，长引用按原字幕分行）

**案例**
（当时他怎么讲的 + 后来他真做了什么。外部事实带来源标记）

**AI 经验**
（唯一专门为用户写的可迁移经验：我能拿它做什么、什么时候会失效）

置信度：★★★
```

规则：

- 四个标签必须**独占一行**，内容另起一行；禁止 `**背景**　正文` 同行。
- `**案例**` 里要区分「他说的」和「他做的」。他做的部分必须带来源层级或外部编号。
- `**AI 经验**` 不是总结，是给用户的行动指令：在什么场景下用、怎么用、什么情况下别用。
- 置信度放在本条最后，单独一行；星级标准见 `verify.md`。
- 四段缺一不可；缺证据时写「待核验」，不要用空话填满。

## 四、ID 规则

| 前缀 | 用途 | 示例 |
| --- | --- | --- |
| `T01`–`T36` | 画像条目 | `T07` 对应 `### 07 ·` |
| `M01`–`M10` | 心智模型 | `M03` |
| `H01`–`H12` | 决策启发式 | `H05` |
| `Q0001` | 逐字引语 | `Q0032` |
| `C0001` | 案例 | `C0117` |
| `E001` | 外部事实 | `E014` |
| `S01` | 传播案例 | `S03` |

- ID 一旦分配，不随排序变化；新增条目用下一个空号。
- 书的索引、核验表、选题清单都引用这些 ID，不要另起一套。
- 引语和案例的 ID 可以写在正文里，但不打断阅读：`（Q0032）` 放在句末。

## 五、排版与符号（全库强制）

只用这 4 个符号：

| 用途 | 符号 | 规则 |
| --- | --- | --- |
| 重点 / 关键概念 | `【】` | 全库唯一强调符；一处最多一个，不连排 |
| 逐字引语 / 原话 | `「」` | 引语内外不再套任何符号 |
| 补充说明 | `（）` | 括号内禁止出现 `【】` |
| 行首标签加粗 | `** **` | 只允许出现在行首：背景/观点/案例/AI 经验、时间线月份、表格表头 |

禁用：

- `『』`
- `（【】）` 这种嵌套
- 句中 `**加粗**`
- 一行内 3 种以上符号
- `——` 连用超过一次

## 六、时间线

- 年份为 H3，事件挂在年份下；年份**从新到旧**，年内月份也从新到旧。
- 禁止把所有年份平铺进一张表。
- 表格只用于「同一维度横向对比」，不用于时间线。

```markdown
### 2026
- **03** SEC 案和解：Rainberry 罚 1000 万美元，对孙本人 dismiss with prejudice，无违法认定（⚖️和解）
- **01** ……

### 2025
……
```

## 七、同题题库（跨人物对比用）

每条画像尽量回答其中 3–8 个问题；回答不了的不用硬凑。问题 ID 用 `Q01`–`Q15`。

1. 你如何定义财富 / 成功？
2. 你最早相信的一条规则是什么？
3. 你做过最反共识的决定是什么？
4. 你如何判断一个机会？
5. 你如何分配时间和注意力？
6. 你如何应对失败 / 被否定？
7. 你如何选择合作对象？
8. 你如何看待规则与监管？
9. 你如何做内容 / 表达？
10. 你如何看待运气与周期？
11. 你最不愿意牺牲什么？
12. 你希望别人记住你什么？
13. 你最近改变了什么看法？
14. 你如何判断一个人是否可信？
15. 如果重来一次，你会怎么做？

用法：在条目末尾加 `同题：Q04 / Q10`，不写进正文。以后多人物对比时，直接按 Q 号拉齐。

## 九、引用口播原文

- 按原字幕分行，不并成一段。
- 每个引用块首行保留 `集号 [起始时间戳] 原文`，后续行只留原文。
- 每行结尾两个空格 + 换行（Markdown 硬换行）。
- 一个字都不改，只在行间插换行。

```markdown
> 045 [12:03] 我当时就觉得这个事能成  
> 因为所有人都在看眼前  
> 只有我在看三年后  
```
