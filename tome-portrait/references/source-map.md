# 来源地图

> 来源地图不是「资料清单」，是「这套语料能证明什么、不能证明什么」的判断书。
> 它决定 G1 闸门要不要补外部材料，也决定画像的「诚实边界」怎么写。

## 一、什么时候写

- 主信息源 `--raw-only` 跑完、`manifest.py` 生成清单之后。
- 外部补充之前。
- 画像写完后，如果新增了大量外部材料，回来更新一次覆盖矩阵。

## 二、模板

```markdown
# <人物>·来源地图

> 生成日期：YYYY-MM-DD
> 主信息源：<合集名 / BV / UP 主>
> 语料截止：<最后一集的日期>
> 已采集：一手 N 集｜外部 N 篇｜访谈 N 篇

## 一、主信息源清单

| 集号 | 标题 | 日期 | 时长 | 字幕/ASR | 播放 | 点赞 | 收藏 | 备注 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 001 | …… | 2016-xx-xx | 12:34 | 字幕 | 12.3万 | 3200 | 1800 | |
| 097 | — | — | — | — | — | — | — | 合集缺号 |

**先看三件事**：
- 缺号：……
- 重复：……
- 无字幕 / 需 ASR：……

## 二、来源结构

| 类型 | 数量 | 说明 |
| --- | --- | --- |
| 一手自述（口播 / 演讲 / 长文） | | 他自己说的 |
| 一手对话（访谈 / 播客 / 对谈） | | 被追问时的即兴反应 |
| 二手整理（媒体转述 / 合集搬运） | | 有编辑加工 |
| 外部评价（批评 / 诉讼 / 监管 / 同行） | | 他者视角 |

**判断**：一手自述占比高，不等于事实密度高；对话和外部材料的比例，决定画像能不能做「言行验证」。

## 三、覆盖矩阵

按年份 × 主题填。主题先用标题和标签粗分，不要求精确。

| 年份 | 钱与投资 | 选择与职业 | 关系与边界 | 规则与风险 | 内容与表达 | 自我与叙事 | 其它 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 2016 | | | | | | | |
| 2017 | | | | | | | |
| … | | | | | | | |
| 2026 | | | | | | | |

填法：写集数或篇数，不写「有 / 无」。例：`001-012（12 集）`。

## 四、缺口

按三类写：

1. **年份缺口**：哪些年份几乎没有语料？
2. **主题缺口**：哪些主题只有他本人自述，没有外部验证？
3. **场合缺口**：有没有访谈 / 对谈 / 被追问 / 公开辩论？只有背稿口播，还是也有即兴应对？

再写一条：

4. **反证缺口**：有没有主动找过「与他自述相反」的材料？找了哪些？结果如何？

## 五、补充清单

| 优先级 | 搜什么 | 去哪搜 | 为什么 | 预期产出 |
| --- | --- | --- | --- | --- |
| P0 | 2019–2021 监管与诉讼 | 司法文件 / 权威媒体 | 时间线断档，且直接影响「规则与风险」类 | 3–5 篇外部材料 |
| P1 | 近 12 个月访谈 | 播客 / 视频访谈 | 检验观点是否漂移 | 2–3 篇对话 |
| P2 | 同行对比 | 行业媒体 | 建立参照系 | 1 篇对比 |

**优先级规则**：
- P0：影响核心结论成立与否，或涉及司法 / 监管 / 重大失败。
- P1：能验证「说 vs 做」的差距。
- P2：能提供参照系，但不影响主结论。
- 一次最多补 10 条；补不完写进诚实边界，不要用模型记忆编。

## 六、判断

用三句话收尾：

1. 这套语料**能**支撑什么（哪些结论可以写）。
2. 这套语料**不能**支撑什么（哪些只能写「待核验」）。
3. 这套语料**偏向**什么（博主的选材偏好、平台算法偏好、时间窗口）。

## 三、常见误判

- **把合集当全集**：合集是博主选的，不是人物全部公开表达。缺号 ≠ 没发生。
- **把口播当事实**：口播是背稿输出，事实密度低，观点密度高；要和外部材料对照。
- **把重复当复现**：同一套话在 10 集里重复，只算 1 个证据，不算 10 个。
- **把标题当主题**：标题党式的标题不等于内容覆盖；抽样读 3–5 集再定主题。
- **把播放量当影响力**：站内播放受推荐算法影响；传播复盘要单独做，不要混进画像。
- **把「没搜到」当「没有」**：搜索能力有边界；写「未找到」，不写「不存在」。

## 四、<人物>案例（参考）

- 主信息源：B站合集「<人物>」137 个视频，编号 1–145，缺 097/115/117/118/119/121/122/131。
- 时间跨度：2016–2017 为主，2026 年有少量新访谈。
- 缺口：2018–2025 的口播几乎空白；监管 / 诉讼 / 失败项目主要靠外部材料补。
- 补充重点：SEC 案、白皮书争议、Steem 治理战、The Verge 调查、巴菲特午餐、TRON 生态数据。
- 结论：画像能支撑「他早年怎么想、怎么做」；不能只凭口播证明「他后来一直这样想」。所以 2.0 加了外部行为验证和言行漂移。
