# tome-portrait · 公众人物解构

从一条合集链接开始，产出一套可检索、可核验、可成书的人物分析。

**范围：第 1–5 环 + 第 7 环。第 6 环（自己批注内化）不介入。**

## 先确认三件事（只问一次）

1. 人物名
2. 主信息源链接（B站合集/视频；没有就说「无」）
3. 输出目录（默认由共享配置决定：folder 模式 `<信息源根目录>/<人物>/`；obsidian 模式 `<Obsidian库>/topics/<人物>/`）

能从链接推断的（UP 主、合集名）直接推断，说明假设后继续，不要反复问。

## 输出物

```text
<项目目录>/

├── 00-收集-外部/            外部材料（带来源层级 / 强度 / URL）
├── 10-画像/
│   ├── _调研/               分片提炼（8 节固定体例）
│   ├── _调研-外部/          外部维度调研（A–I）

│   └── <人物>·核验表.md
```

## 流程（三个闸门，其余连续跑）

| 步 | 做什么 | 读 |
|---|---|---|
| 0 | 初始化目录 + `_meta/progress.md` | `scripts/new_project.py` |
| 1 | 采集主信息源：先 `--raw-only` 全量落盘，再分批 `--distill-only` | `tome-bili` skill |
| 2 | 来源地图：清点一手/二手/外部，做年份 × 主题覆盖矩阵，列缺口和补充清单 | `references/source-map.md` |
| **G1** | **人工确认补充范围** | — |
| 3 | 按缺口补外部材料，每条标来源层级 + 强度 + URL | `references/workflow.md` |
| 4 | 分片调研：每 12–16 集一片，并行子代理，8 节固定体例 | `references/workflow.md` |
| 5 | 综合画像：6 类、26–36 条、四段式、4 道验证 | `references/portrait-spec.md` |
| **G2** | **人工确认画像结构（分类、条目、语气）** | — |
| 6 | 核验：每条结论打 3 星，列矛盾清单，对核心结论做反证搜索 | `references/verify.md` |
| 7 | 成书：一本内容源，md + epub 两种格式 | `references/book.md` |
| 8 | 传播复盘（可选）：8–12 个案例 + 10–15 个选题 + 3–5 个结构模板；无互动数据时用代理指标 | `tome-spread` skill |
| **G3** | **最终验收** | — |

三个闸门各停一次，其余全自动连续执行。不要把每个小节都拿来问。

## 三条硬规矩

1. **来源分层**：司法/官方 > 权威媒体 > 行业媒体 > 传闻。每条外部事实带 `✅实锤 / ⚖️和解 / 🔶指控 / ❓传闻` + URL。
2. **起诉 ≠ 定罪，和解 ≠ 认罪，指控 ≠ 事实。** 画像正文不写未经司法认定的定性。
3. **原话不改**。引用口播按原字幕分行，保留集号和时间戳；只做去口语赘词和常识性人名校正，不做概括式改写。

## 模型档位

- `claude`（默认）：逐集蒸馏交给 Claude Code；来源地图、缺口判断、综合画像、核验、成书也在本会话完成。
- `openai` / `ollama`：逐集蒸馏、打标签、去重、初筛交给脚本批量跑；判断类工作仍由 Claude 做。
- 人：G1 / G2 / G3 三个闸门。配置见 `tome/references/setup.md`。

## 断点续跑

每完成一步，勾掉 `_meta/progress.md` 并记下产物路径。中断后先读 `_meta/progress.md`，从第一个未勾选项继续；已存在的文件默认跳过，不重爬、不重写。
