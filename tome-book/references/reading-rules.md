# 阅读版规则

这些规则来自 tome-book 的 37 条阅读优化经验，已参数化。构建器默认全部执行；要改行为，改脚本里的常量，不要改生成的 epub。

## 一、页面与排版

1. **页边距 14px**。手机阅读左右各留 14px，比默认的 0 更稳，比 20px 更省屏。
2. **行高 1.75**。中文长段落低于 1.6 会挤，高于 1.9 会散。
3. **正文 1em，标题层级 1.85 / 1.42 / 1.18 / 1.06**。H1 只用于章，不用于小节。
4. **H1 前强制分页**，但扉页和篇章页用 `page-break-before: avoid`，否则会多出空白页。
5. **标题后禁止分页**（`page-break-after: avoid`），避免标题孤零零留在页底。
6. **卡片 `page-break-inside: avoid`**，案例卡不被拆成两页。
7. **段落 `widows: 2; orphans: 2`**，不出现单行孤行。
8. **正文两端对齐**（`text-align: justify`），中文用 `inter-ideograph`。
9. **`overflow-wrap: break-word`**，长 URL、长英文名不撑破屏幕。
10. **不用固定宽度**。所有布局用百分比/em，适配 390px 到 iPad。

## 二、书的结构

11. **顺序固定**：封面 → 扉页 → 总纲 → 第一篇 → 第二篇 →（第三篇）→（附录 F）→（附录 G）。所有附录都放顶层。
12. **扉页独立**，不跟总纲挤在一页。含书名、副标题、口述/整理、版本、开始阅读。
13. **篇章页独立**，含 PART ONE/TWO/THREE、篇名、一句导语、一条阅读提示。
14. **篇章页不是普通章节**：正文只有 3–4 行，居中偏上，留白占 2/3。
15. **总纲第一页就是内容**，不要放目录。目录放在「怎么读」之后。
16. **书内目录可点击**，按 H2 分组、H3 列条目；没有子项的 H2 直接做成链接。
17. **nav.xhtml 与 toc.ncx 同时生成**。微信读书/iBooks 用 nav，老阅读器用 NCX。
18. **nav 树深度 3**：书 → 篇 → 章；总纲下挂 H2/H3。

## 三、内容清洗

19. **去 frontmatter**。YAML 进正文会变成一段乱码。
20. **H1 统一**。每篇只能有一个 H1，格式 `NNN · 主题` 或 `外部素材 NN · 主题`。
21. **`---` 转 `***`**。单独一行 `---` 在 pandoc 里可能是 YAML 结束符或 setext 标题。
22. **标题前补空行**。紧跟在列表后面的 `##` 会被当成列表内容。
23. **口播稿分段**。按约 280 字一段，段落之间空一行；不要把整篇塞进一个 `<p>`。
24. **时间戳弱化**。阅读版只保留每段开头的时间戳，字号 0.78em、透明度 0.5；归档版保留全部。
25. **ASR 引用去时间戳**。`> 001 [00:12] 文本` 转成 `> 文本`，否则引用块里全是编号。
26. **去重复观点**。「核心观点速览」和「学习记录 > 核心观点」逐条相同时，删后者。
27. **原视频链接只到视频页**。不加 `?t=` 时间戳：链接会失效，且阅读时不需要。

## 四、表格

28. **四列案例表转卡片**。表头为「案例 / 一句话故事 / 支撑观点 / 可复用场景」时，每行一张卡。
29. **两列对照表转定义列表**。左列加粗做术语，右列做解释。
30. **两列「他讲的 / 他做的」也转卡片**，不要用定义列表：这是对照，不是释义。
31. **其余宽表兜底转卡片**。第一列是序号时，用第二列做标题，序号并入字段。
32. **正文里不留 `<table>`**。手机上横向滚动是阅读体验的硬伤；校验器会把残留表格判为失败。

## 五、文件与元数据

33. **封面 1200×1800 PNG**，比例 2:3；`cover.xhtml` 用 `<img>` 铺满，不用 SVG。
34. **`mimetype` 必须是 zip 的第一个文件，且不压缩**。命令：`zip -X0 book.epub mimetype`，再 `zip -Xr9 book.epub META-INF EPUB`。
35. **OPF 补齐**：`dc:description`、3 个 `dc:subject`、`dc:contributor`（编辑，role=edt）；移除封面 item 的 `properties="svg"`。
36. **每个 xhtml 注入 viewport**：`width=device-width, initial-scale=1`；iBooks 的 `specified-fonts` 设为 `false`，允许用户换字体。
37. **`<title>` 必须是真实章节名**。阅读器的书签、进度、搜索都读它；`ch001` 这种占位名会让目录变乱。

## 构建后校验

```bash
python3 ~/.claude/skills/tome-book/scripts/validate.py "/path/book.epub"
```

必须全部通过：

- mimetype 第一个 + stored
- OPF/XML 可解析
- manifest 文件齐全、spine 引用有效
- nav/NCX 链接无 404、锚点存在
- 每章 `<title>` 非空
- 0 个残留 `<table>`
- 封面、扉页在 spine 里
- 篇章页数量 = 实际篇数

## 常见误判

- **「书里看起来有空行」**：多半是 H1 的 `page-break-before: always` 加上篇章页没设 `avoid`。检查篇章页的 H1 是否带 `part-title`。
- **「目录点不动」**：锚点被中文 slug 改过。重跑构建，不要手改 xhtml。
- **「封面在微信读书里被裁」**：封面不是 2:3，或用了 `object-fit: contain`。保持 1200×1800。
- **「口播稿还是一大段」**：标题不匹配 `## 附：完整口播稿` / `## 附：原文口播稿`，或原文不是 `[MM:SS] 文本` 一行一句。
- **「合并 md 和 epub 内容不一致」**：合并 md 是同一份 `pandoc_md` 派生的；如果手动改过 md，要重新构建 epub。

## 阅读版做了什么

1. 去 frontmatter；H1 统一成 `NNN · 主题`。
2. `---` 分隔线转 `***`，避免被当成 YAML 或 setext 标题。
3. 每篇 H1 后插入原视频链接（只链到视频页，不带时间戳）。
4. 表格转卡片：案例表、对照表、宽表都不再横向滚动。
5. 口播稿按约 280 字分段，每段只留开头时间戳，弱化为灰色小字。
6. 删除「核心观点速览」与「学习记录」里逐条重复的内容。
7. 封面 → 扉页 → 总纲 → 篇章页 → 逐章；篇章页带 PART ONE/TWO/THREE。
8. 总纲里生成可点击的书内目录；导航同时生成 nav.xhtml 和 toc.ncx。
9. 书内目录/锚点用相对链接；原视频外链保持绝对 URL。长 URL 自动换行，避免撑破页面。
10. CSS：行高 1.75、页边距 14px、标题避孤行、卡片避跨页。
11. OPF 补 description / subject / contributor，封面从 SVG 页改成 `<img>`。
12. `mimetype` 第一个且不压缩，zip 用 `-X0` + `-Xr9`。
13. 多个附录都放顶层，不嵌进最后一篇；附录标题必须以「附录」开头。

## 排查

| 现象 | 原因 |
| --- | --- |
| 章节数只有总纲+外部 | 逐集文件名里没有 `NNN：`，或不在 `00-收集/` |
| 微信文章一篇都没进书 | 文件名是文章标题；先 staging 再用 `--config`，见 `references/wechat-book.md` |
| 某篇没进书 | 文件名不匹配 `NNN：` / `外部NNN：`，或位于 `_` 开头的文件 |
| 附录嵌进上一篇 / 顺序错 | 附录标题没有以「附录」开头；改成 `附录 G · ……` |
| XML mismatched tag，或合并 md 有 `&lt;` | 正文有裸 `<`；先替换 `<滑动查看下一张图片>`，再统一转 `&lt;` |
| 阅读版没有配图 | 正常取舍；配图保留在 Obsidian 原笔记和 Eagle |
| 目录链接 404 | 章节 H1 被改过；重跑构建即可 |
| 表格还在 | 表头不在已知四列模板内，且列数异常；看 `reading-rules.md` 的兜底规则 |
| 微信读书里封面空白 | 封面不是 PNG/JPG，或 OPF 里没有 `cover-image` |
| 口播稿没分段 | 标题不是 `## 附：完整口播稿` 或 `## 附：原文口播稿` |
| 中文文件名打包失败 | 用 `--work` 指到 `/tmp`，避开 iCloud 同步冲突 |
